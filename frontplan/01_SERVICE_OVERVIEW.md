# 서비스 개요

## 서비스 소개

**냉파 고수**는 냉장고나 영수증 사진을 분석하여 식재료를 자동 등록하고, 소비기한 관리 및 맞춤형 레시피를 제안하는 서비스입니다. 특히 **AI 인식 오류를 사용자가 직접 교정하는 프로세스**를 통해 데이터의 신뢰도를 높이고, 부족한 재료는 즉시 구매로 연결합니다.

## 타겟 사용자

| 사용자 유형      | 설명                                      | 주요 니즈                            |
| ---------------- | ----------------------------------------- | ------------------------------------ |
| 자취생/1인 가구  | 혼자 식사를 준비하는 사용자               | 식재료 낭비 최소화, 간단한 레시피    |
| 바쁜 직장인      | 요리에 시간을 많이 투자하기 어려운 사용자 | 빠른 식재료 등록, 간편한 레시피 추천 |
| 주부/가정 요리사 | 가족 식사를 책임지는 사용자               | 체계적인 재고 관리, 다양한 레시피    |
| 요리 초보자      | 요리를 배우고 싶은 사용자                 | 단계별 레시피, 커뮤니티 조언         |

## 핵심 가치

1. **Scan & Manage**: 사진 한 장으로 끝나는 스마트한 재료 관리
2. **Trustworthy Data**: 사용자의 직접 수정을 통한 데이터 무결성 확보
3. **Seamless Action**: 추천에서 구매, 조리 후 커뮤니티 공유까지 끊김 없는 UX

## 사용자 여정 (User Flow)

```
1. [로그인] 소셜 로그인 (카카오/구글)
      │
      ▼
2. [인식] 사진 업로드 및 AI 분석
   │ • 영수증 / 냉장고 / 구매내역 사진
   │
   ▼
3. [검토] 분석 결과 확인 및 사용자 직접 수정 (데이터 보정)
   │ • 오인식 재료명 수정
   │ • 불필요 항목 삭제
   │ • 미인식 항목 수동 추가
   │
   ▼
4. [추천] 홈 화면에서 80% 매칭 레시피 확인
   │ • 소비기한 임박 식재료 우선 활용 레시피
   │ • 유튜브 조리 영상 연결
   │
   ▼
5. [구매] 부족 재료 쇼핑몰 이동 및 구매 (딥링크)
   │ • 쿠팡 / 마켓컬리 / 네이버쇼핑
   │
   ▼
6. [인증] 요리 완성 사진 업로드
   │ • AI 싱크로율 확인 (레시피 원본 vs 내 요리 비교 점수)
   │ • 커뮤니티 공유
   ▼

[홈으로 돌아가기]
```

## 차별점

- **AI 이미지 분석 + 사용자 교정**: 영수증/냉장고 사진 자동 인식 후 사용자 직접 검토/수정
- **데이터 신뢰도 99%**: 사용자 교정 프로세스로 데이터 무결성 확보
- **AI 싱크로율 판단**: 레시피 원본 vs 사용자 요리 사진 AI 비교 점수화 (Gamification)
- **쇼핑 딥링크**: 부족 식재료 쿠팡/마켓컬리/네이버쇼핑 연결

## MVP 범위

### 포함 ✅ (MVP 1)

- 회원가입/로그인 (소셜 로그인: 카카오/구글)
- 영수증/냉장고/구매내역 이미지 업로드
- AI 이미지 분석 및 식재료 자동 추출 (Google Vision API)
- **분석 결과 프리뷰 및 사용자 교정 기능**
- 식품의약품안전처 소비기한 데이터 매칭
- 중복 아이템 푸시 알림 및 통합 관리 제안
- 보유 식재료 80% 이상 매칭 레시피 우선 추천
- 유튜브 레시피 영상 연결 (YouTube Data API v3)
- 커뮤니티 공유 + AI 싱크로율 판단
- 홈 화면 추천 레시피 썸네일

### 제외 ❌ (이후 버전)

- 쇼핑몰 연동 (쿠팡/마켓컬리/네이버쇼핑)
- 이 달의 베스트 음식 시스템
- 프리미엄 구독 기능
- 음성 인식 식재료 등록
- 가계부 연동
