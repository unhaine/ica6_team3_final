# 기능 명세

## MVP 기능 (필수)

### F1. 회원 인증

- **설명**: 이메일/소셜 로그인을 통한 사용자 인증
- **사용자 스토리**: 사용자는 이메일 또는 소셜 계정으로 로그인하여 개인화된 냉장고를 관리할 수 있다
- **우선순위**: 🔴 높음
- **상태**: ⏳ 예정
- **예상 공수**: 2일

**상세 요구사항**

- [ ] 이메일/비밀번호 회원가입
- [ ] 이메일/비밀번호 로그인
- [ ] 카카오 소셜 로그인
- [ ] 구글 소셜 로그인
- [ ] 비밀번호 재설정
- [ ] JWT 토큰 기반 세션 관리

---

### F2. 식재료 이미지 분석 및 등록

- **설명**: 영수증/냉장고/구매내역 이미지를 AI로 분석하여 식재료 자동 추출
- **사용자 스토리**: 사용자는 영수증이나 냉장고 사진을 업로드하면 AI가 식재료를 자동으로 인식하고 등록해준다
- **우선순위**: 🔴 높음
- **상태**: ⏳ 예정
- **예상 공수**: 5일

**상세 요구사항**

- [ ] 이미지 업로드 UI (드래그 앤 드롭, 파일 선택)
- [ ] 카메라 촬영 기능 (모바일)
- [ ] Google Vision API 연동
- [ ] 영수증 OCR 분석
- [ ] 냉장고 내부 이미지 물체 인식
- [ ] **분석 결과 프리뷰 및 교정 UI**
  - [ ] AI 분석 직후 리스트 형태로 데이터 노출
  - [ ] 오인식된 재료명 수정 기능
  - [ ] 불필요 항목 삭제 기능
  - [ ] 미인식 항목 수동 추가 기능
- [ ] 식재료 확정 및 저장

---

### F3. 소비기한 관리

- **설명**: 식품의약품안전처 데이터를 활용한 소비기한 자동 설정 및 알림
- **사용자 스토리**: 사용자는 등록된 식재료의 권장 소비기한을 자동으로 받고, 기한이 임박하면 알림을 받는다
- **우선순위**: 🔴 높음
- **상태**: ⏳ 예정
- **예상 공수**: 3일

**상세 요구사항**

- [ ] 식품의약품안전처 품목별 소비기한 데이터 연동
- [ ] 식재료-소비기한 자동 매칭
- [ ] 구매일 기준 D+N일 표시
- [ ] 권장 소비기한 D-3일 등 알림
- [ ] 푸시 알림 발송 (웹 푸시)
- [ ] 소비기한 수동 수정 기능

---

### F4. 중복 아이템 알림

- **설명**: 이미 등록된 식재료가 다시 등록될 때 사용자에게 알림
- **사용자 스토리**: 사용자가 이미 등록된 식재료를 다시 등록하려 할 때, 시스템이 중복 여부를 알려준다
- **우선순위**: 🟡 중간
- **상태**: ⏳ 예정
- **예상 공수**: 1일

**상세 요구사항**

- [ ] 식재료 등록 시 기존 목록과 비교
- [ ] 중복 발견 시 팝업/토스트 알림
- [ ] 수량 합산 또는 새로 추가 선택 옵션

---

### F5. 내 냉장고 (식재료 목록)

- **설명**: 보유 중인 식재료 목록 조회 및 관리
- **사용자 스토리**: 사용자는 현재 보유한 식재료 목록을 확인하고 수정/삭제할 수 있다
- **우선순위**: 🔴 높음
- **상태**: ⏳ 예정
- **예상 공수**: 2일

**상세 요구사항**

- [ ] 식재료 목록 카드/리스트 뷰
- [ ] 소비기한 가까운 순 정렬
- [ ] 카테고리별 필터 (채소, 육류, 유제품 등)
- [ ] 식재료 상세 보기
- [ ] 식재료 수량 수정
- [ ] 식재료 삭제 (사용 완료)
- [ ] 검색 기능

---

### F6. 레시피 추천

- **설명**: 보유 식재료 기반 맞춤 레시피 추천
- **사용자 스토리**: 사용자는 현재 보유한 식재료로 만들 수 있는 레시피를 추천받는다
- **우선순위**: 🔴 높음
- **상태**: ⏳ 예정
- **예상 공수**: 4일

**상세 요구사항**

- [ ] 보유 식재료 80% 이상 일치하는 레시피 우선 추천
- [ ] 레시피 카드 UI (썸네일, 제목, 필요 재료, 매칭률)
- [ ] 레시피 상세 보기 (재료, 조리법)
- [ ] 유튜브 레시피 영상 링크 연결 (YouTube Data API v3)
- [ ] 보유하지 않은 식재료 표시 + 쇼핑 딥링크
- [ ] AI 기반 레시피 생성 (Gemini 1.5 Pro)

---

### F7. 홈 화면 레시피 피드

- **설명**: 홈 화면에 냉장고 기반 추천 레시피 썸네일 표시
- **사용자 스토리**: 사용자는 앱 접속 시 홈 화면에서 바로 추천 레시피를 확인할 수 있다
- **우선순위**: 🟡 중간
- **상태**: ⏳ 예정
- **예상 공수**: 2일

**상세 요구사항**

- [ ] 추천 레시피 캐러셀/그리드
- [ ] 매칭률 아이콘/배지
- [ ] 빠른 레시피 상세 이동

---

### F8. 커뮤니티

- **설명**: 사용자 간 레시피/요리 팁 공유 게시판
- **사용자 스토리**: 사용자는 자신의 요리 결과물과 꿀팁을 커뮤니티에 공유하고, 다른 사용자의 게시글을 볼 수 있다
- **우선순위**: 🟡 중간
- **상태**: ⏳ 예정
- **예상 공수**: 3일

**상세 요구사항**

- [ ] 게시글 작성 (제목, 내용, 이미지)
- [ ] 게시글 목록 조회
- [ ] 게시글 상세 보기
- [ ] 게시글 수정/삭제
- [ ] 좋아요 기능
- [ ] 댓글 기능
- [ ] 카테고리 (레시피 공유, 꿀팁, 질문)
- [ ] **AI 싱크로율 판단** (레시피 원본 vs 사용자 요리 사진 비교 점수화)
