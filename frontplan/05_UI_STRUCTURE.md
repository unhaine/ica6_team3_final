## 컴포넌트 목록 (Mobile-First)

### 공통 컴포넌트

- [ ] **BottomNavigation** - 하단 탭 네비게이션 (5개 탭)
- [ ] **TopAppBar** - 상단 앱 바 (뒤로가기, 제목, 액션)
- [ ] **Button** - 버튼 (Primary, Secondary, Ghost)
- [ ] **Input** - 텍스트 입력 (터치 최적화)
- [ ] **Card** - 카드 (터치 피드백 포함)
- [ ] **BottomSheet** - 바텀 시트 (모달 대체)
- [ ] **Toast** - 토스트 알림
- [ ] **Skeleton** - 로딩 스켈레톤
- [ ] **PullToRefresh** - 당겨서 새로고침
- [ ] **SwipeableCard** - 스와이프 액션 카드

### 페이지별 컴포넌트

- [ ] **IngredientCard** - 식재료 카드 (스와이프 삭제)
- [ ] **IngredientEditRow** - 식재료 수정 행 (터치 인라인 수정)
- [ ] **RecipeCard** - 레시피 카드 (매칭률 바 포함)
- [ ] **MatchRateBar** - 매칭률 프로그레스 바
- [ ] **CategoryChips** - 카테고리 칩 (가로 스크롤)
- [ ] **ExpiryBadge** - 소비기한 배지 (색상 구분)
- [ ] **ImageUploader** - 이미지 업로더 (카메라/갤러리)
- [ ] **SocialLoginButton** - 소셜 로그인 버튼
- [ ] **SyncRateCircle** - 싱크로율 원형 차트
- [ ] **ShoppingLinkButton** - 쇼핑 딥링크 버튼

## 터치 인터랙션 가이드

### 제스처

| 제스처      | 위치        | 동작                |
| ----------- | ----------- | ------------------- |
| Tap         | 카드, 버튼  | 선택, 이동          |
| Long Press  | 식재료 카드 | 빠른 삭제/수정 메뉴 |
| Swipe Left  | 식재료 카드 | 삭제                |
| Swipe Right | 식재료 카드 | 사용 완료           |
| Pull Down   | 목록 화면   | 새로고침            |
| Scroll      | 전체        | 콘텐츠 탐색         |

### 터치 타겟 크기

- **최소 터치 영역**: 44px × 44px (Apple HIG 기준)
- **버튼 높이**: 48px ~ 56px
- **간격**: 최소 8px
