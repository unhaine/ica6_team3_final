# 📍 사용자 흐름 (User Flow)

> MVP 핵심 시나리오: 냉장고 사진 → AI 분석 → 레시피 추천 → 요리 인증

---

## 📋 단계별 상세

### Step 1: 로그인 (/test/login)

**목적**: 사용자 인증

| 항목 | 내용                  |
| ---- | --------------------- |
| 입력 | 소셜 로그인 버튼 클릭 |
| 처리 | NextAuth.js 인증      |
| 출력 | 세션 생성 → 메인 이동 |

**MVP 간소화**: 로그인 없이 로컬 스토리지로 임시 데이터 저장 (개발용)

---

### Step 2: 메인화면 (/test)

**목적**: 대시보드 & 진입점

| 섹션          | 내용                       |
| ------------- | -------------------------- |
| Hero          | "오늘 뭐 먹지?" + CTA 버튼 |
| 소비기한 임박 | 알림 카드 (가로 스크롤)    |
| 추천 레시피   | 80% 매칭 레시피 카드       |

**CTA 버튼 동작**:

- `📷 사진으로 등록하기` → `/test/upload`

---

### Step 3: 사진 등록 (/test/upload)

**목적**: 이미지 업로드 및 AI 분석 요청

**상태 흐름**:

1. **타입 선택**: [냉장고] 또는 [영수증] 버튼 클릭
2. **업로드**: OS 파일 선택창 오픈 및 이미지 선택
3. **미리보기**: 선택한 이미지 표시 + **중앙에 'AI 분석하기' 버튼 노출**
4. **분석**: 버튼 클릭 시 `ANALYZING` 상태 진입

**API 매핑**:
| 구분 | API | 설명 |
| --------- | ------------ | ------------------------------------- |
| `fridge` | gemini-flash | 냉장고 사진 → 객체 탐지 + 바운딩 박스 |
| `receipt` | receipt-ocr | 영수증 → 텍스트 인식 |

---

### Step 4: AI 분석 결과 (/test/review)

**목적**: 인식된 식재료 검토 및 교정

> ⚠️ **중요**: 냉장고 사진과 영수증에 따라 UI가 다름

---

#### 4a. 냉장고 사진 → 바운딩박스 UI (`?type=fridge`)

| 기능                        | 설명                                   |
| --------------------------- | -------------------------------------- |
| **이미지 + 박스 오버레이**  | 원본 냉장고 사진 위에 바운딩 박스 표시 |
| **박스 드래그**             | 위치 수정 (x, y 좌표 변경)             |
| **라벨 클릭 → 텍스트 수정** | 식재료명 인라인 수정                   |
| **박스 삭제**               | 오인식 항목 제거                       |
| **박스 추가**               | 미인식 식재료 수동 추가                |
| **확인 버튼**               | 검토 완료 → 레시피 추천으로 이동       |

**컴포넌트**: `BoundingBoxCanvas` 확장

```
┌────────────────────────┐
│  (냉장고 이미지)       │
│  ┌──────┐ ┌──────┐  │ ← 바운딩박스 오버레이
│  │  우유 │ │ 당근  │  │   드래그로 위치 수정
│  └──────┘ └──────┘  │   클릭으로 텍스트 수정
│       ┌─────────┐   │
│       │  김치    │   │
│       └─────────┘   │
└────────────────────────┘
    [➕ 추가] [✅ 완료]
```

---

#### 4b. 영수증/구매내역 → 리스트 UI (`?type=receipt`)

| 기능            | 설명                             |
| --------------- | -------------------------------- |
| **리스트 표시** | 인식된 식재료 카드 목록          |
| **인라인 수정** | 식재료명, 수량, 단위 직접 수정   |
| **항목 삭제**   | 스와이프 또는 삭제 버튼          |
| **항목 추가**   | 미인식 식재료 수동 추가          |
| **확인 버튼**   | 검토 완료 → 레시피 추천으로 이동 |

**컴포넌트**: shadcn `Card` + 인라인 `Input`

```
┌────────────────────────┐
│ 🧀 인식된 식재료 (5개)    │
├────────────────────────┤
│ ┌────────────────────┐ │
│ │ [삼격살    ] [300g]│ │ ← 클릭하면 인풀 수정
│ │               [휴지통]│ │
│ └────────────────────┘ │
│ ┌────────────────────┐ │
│ │ [양파      ] [3개] │ │
│ │               [휴지통]│ │
│ └────────────────────┘ │
│ ┌────────────────────┐ │
│ │ [우유      ] [1L]  │ │
│ └────────────────────┘ │
│                        │
│    [➕ 추가] [✅ 완료]
```

---

#### 공통 상태 흐름

```
[검토 화면] ─── 수정/삭제/추가 ─── [확인 버튼] ───▶ /test/recipes
```

| 확인 버튼 클릭 시 | 동작                                   |
| ----------------- | -------------------------------------- |
| 데이터 저장       | 수정된 식재료 목록 저장 (localStorage) |
| 페이지 이동       | `/test/recipes` 로 이동                |

---

### Step 5: 레시피 추천 (/test/recipes)

**목적**: 보유 식재료 기반 레시피 추천

| 항목      | 내용                           |
| --------- | ------------------------------ |
| 정렬      | 매칭률 높은 순                 |
| 필터      | 카테고리 (한식/양식/중식 등)   |
| 카드 정보 | 썸네일, 제목, 매칭률, 조리시간 |

**매칭 로직**:

```
매칭률 = (보유 식재료 수 / 필요 식재료 수) × 100
```

---

### Step 6: 레시피 상세 (/test/recipes/[id])

**목적**: 조리법 상세 보기

| 섹션   | 내용                         |
| ------ | ---------------------------- |
| 헤더   | 썸네일, 제목, 조리시간, 인분 |
| 재료   | ✅ 보유 / ❌ 미보유 표시     |
| 조리법 | 단계별 설명                  |
| 유튜브 | 영상 링크 버튼               |
| CTA    | "요리 완료! 인증하기"        |

---

### Step 7: 요리 인증 (/test/verify)

**목적**: 완성된 요리 사진으로 AI 싱크로율 평가

| 항목    | 내용                            |
| ------- | ------------------------------- |
| 입력    | 완성된 요리 사진                |
| AI 분석 | 레시피 원본 vs 사용자 사진 비교 |
| 출력    | 싱크로율 점수 (0~100)           |

**Gamification**:

- 점수 기반 뱃지/칭호
- 랭킹 표시

## 🔀 분기 흐름

### 에러 처리

```
분석 실패 시:
  → 에러 메시지 표시
  → "다시 시도" 버튼
  → 수동 입력으로 전환 가능
```

### 스킵 가능한 단계

```
[사진등록] ─(스킵)─→ [직접입력] → [레시피추천]
```
