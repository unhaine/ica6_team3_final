# 기능 명세 (Feature Specifications)

## 1. 식재료 관리 (Ingredient Management)

### [F-1.1] 멀티모달 인식 (Core)
- **기능**: 사용자가 업로드한 이미지(냉장고, 영수증, 스크린샷)에서 식재료 텍스트 및 이미지를 추출.
- **기술**: Google Vision API, Gemini 1.5 Pro 활용.
- **출력**: 식재료명, 수량(추정), 카테고리.

### [F-1.2] 분석 결과 프리뷰 및 교정
- **기능**: AI 분석 직후 결과 리스트를 사용자에게 팝업/모달 형태로 제공.
- **동작**:
    - 오인식된 텍스트 수정 기능.
    - 불필요한 항목 스와이프/터치로 삭제.
    - 리스트에 없는 항목 수동 추가.
    - **UX 목표**: 3초 이내에 수정 완료 유도.

### [F-1.3] 소비기한 자동 매칭 및 알림
- **기능**: 등록된 식재료명과 '식품의약품안전처 품목별 DB'를 매칭하여 권장 소비기한 자동 설정.
- **알림**: 소비기한 임박(D-3, D-1) 시 푸시 알림 발송.

### [F-1.4] 중복 방지 로직
- **기능**: 신규 등록 시 기존 냉장고 인벤토리에 같은 이름의 재료가 있다면 경고 및 합치기 제안.
- **목표**: 데이터 중복 등록으로 인한 관리 혼선 방지.

## 2. 레시피 추천 (Recipe Recommendation)

### [F-2.1] 보유 재료 기반 매칭
- **기능**: 사용자 냉장고 인벤토리 vs 만개의 레시피 DB 매칭.
- **로직**: 보유 재료 포함 비율이 80% 이상인 레시피를 우선 노출.
- **정렬**: 매칭률 순, 유통기한 임박 재료 사용 순.

### [F-2.2] 유튜브 레시피 큐레이션
- **기능**: 추천된 레시피 상세 화면에서 관련 유튜브 조리 영상 자동 재생/링크.
- **기술**: YouTube Data API v3 (레시피명 + '만들기' 키워드 검색).

### [F-2.3] 부족 재료 쇼핑 딥링크
- **기능**: 레시피에서 부족한 나머지 20% 재료에 대해 구매 링크 제공.
- **연동**: 쿠팡, 마켓컬리, 네이버 쇼핑 검색 링크 생성.

## 3. 커뮤니티 (Community)

### [F-3.1] 꿀팁 피드 & 인증
- **기능**: 사용자가 만든 요리 사진과 팁을 업로드하는 SNS 형태의 피드.

### [F-3.2] AI 싱크로율 분석 (Gamification)
- **기능**: 사용자가 올린 요리 사진과 레시피 원본 사진을 AI가 비교.
- **효과**: 싱크로율 점수(%)를 부여하여 재미 요소 및 랭킹 산정.
