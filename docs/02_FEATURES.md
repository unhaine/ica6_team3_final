# 기능 명세

## MVP 기능 (필수)

### F1. 이미지 업로드 및 미리보기

- **설명**: 사용자가 카메라로 촬영하거나 갤러리에서 이미지를 선택하여 업로드
- **사용자 스토리**: 사용자는 냉장고 내부 사진을 업로드하면 화면에서 미리볼 수 있다
- **우선순위**: 🔴 높음
- **상태**: ⏳ 예정
- **예상 공수**: 0.5일
- **담당**: -

**상세 요구사항**

- [ ] 파일 선택 버튼 (input type="file")
- [ ] 카메라 촬영 버튼 (모바일 capture 속성)
- [ ] 드래그 앤 드롭 업로드 지원
- [ ] 이미지 미리보기 표시
- [ ] 지원 포맷: JPG, PNG, WEBP
- [ ] 최대 파일 크기 제한 (10MB)
- [ ] 이미지 리사이징 (필요시)

---

### F2. Google Vision API 연동 및 객체 탐지

- **설명**: 업로드된 이미지를 Google Vision API로 전송하여 객체 탐지 수행
- **사용자 스토리**: 사용자는 사진을 업로드하면 자동으로 식료품이 인식된다
- **우선순위**: 🔴 높음
- **상태**: ⏳ 예정
- **예상 공수**: 1일
- **담당**: -

**상세 요구사항**

- [ ] Google Vision API 클라이언트 설정
- [ ] 이미지 Base64 인코딩
- [ ] Object Localization API 호출
- [ ] API 응답 파싱 및 정규화
- [ ] 에러 핸들링 (네트워크 오류, API 오류)
- [ ] 로딩 상태 표시

**API 호출 예시**

```javascript
const response = await visionClient.objectLocalization({
  image: { content: base64Image },
});
```

---

### F3. Bounding Box 시각화

- **설명**: 탐지된 객체를 YOLO 스타일의 Bounding Box로 이미지 위에 표시
- **사용자 스토리**: 사용자는 사진 위에 탐지된 식료품 위치를 박스로 확인할 수 있다
- **우선순위**: 🔴 높음
- **상태**: ⏳ 예정
- **예상 공수**: 1일
- **담당**: -

**상세 요구사항**

- [ ] Canvas 또는 SVG 기반 오버레이 렌더링
- [ ] 각 객체별 색상 구분
- [ ] 박스 좌표 정규화 (normalized vertices → pixel)
- [ ] 반응형 리사이징 대응
- [ ] 박스 스타일링 (선 두께, 색상, 투명도)

---

### F4. Confidence Score 표시

- **설명**: 각 Bounding Box 상단에 품목명과 신뢰도 표시
- **사용자 스토리**: 사용자는 각 식료품의 이름과 인식 정확도를 확인할 수 있다
- **우선순위**: 🔴 높음
- **상태**: ⏳ 예정
- **예상 공수**: 0.5일
- **담당**: -

**상세 요구사항**

- [ ] 라벨 텍스트 렌더링 (품목명 + %)
- [ ] 라벨 배경색 (가독성 확보)
- [ ] 한글 품목명 변환 (필요시)
- [ ] 낮은 신뢰도 표시 (< 50% 경고 색상)

**표시 예시**

```
┌─────────────────┐
│ 🍎 사과 (92%)   │
├─────────────────┤
│                 │
│   [객체 영역]   │
│                 │
└─────────────────┘
```

### F5. 객체 박스 드래그 및 수정

- **설명**: 사용자가 잘못 인식된 박스를 드래그하여 위치/크기 수정
- **사용자 스토리**: 사용자는 잘못된 박스를 드래그하여 올바른 위치로 수정할 수 있다
- **우선순위**: 🟡 중간
- **상태**: ⏳ 예정
- **예상 공수**: 1.5일
- **담당**: -

**상세 요구사항**

- [ ] 박스 선택 (클릭/터치)
- [ ] 박스 이동 (드래그)
- [ ] 박스 크기 조절 (리사이즈 핸들)

- [ ] 박스 삭제 기능
- [ ] 새 박스 수동 추가
