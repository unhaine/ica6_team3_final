# UI / 화면 구조

## 페이지 목록

| 경로              | 페이지명      | 설명                      | 인증 |   레이아웃    | 상태 |
| ----------------- | ------------- | ------------------------- | :--: | :-----------: | :--: |
| `/`               | 랜딩          | 서비스 소개 + 시작하기    |  ❌  |     None      |  ⏳  |
| `/login`          | 로그인        | 소셜 로그인               |  ❌  |     None      |  ⏳  |
| `/onboarding`     | 온보딩        | 3단계 설문                |  ✅  |     None      |  ⏳  |
| `/home`           | 홈 (대시보드) | 레시피 추천 + 냉장고 현황 |  ✅  | 기본 레이아웃 |  ⏳  |
| `/fridge`         | 나의 냉장고   | 식재료 리스트             |  ✅  | 기본 레이아웃 |  ⏳  |
| `/community`      | 커뮤니티      | 요리 공유 피드            |  ✅  | 기본 레이아웃 |  ⏳  |
| `/profile`        | 프로필        | 사용자 설정               |  ✅  | 기본 레이아웃 |  ⏳  |
| `/camera`         | 카메라        | 사진 촬영/업로드          |  ✅  |  Fullscreen   |  ⏳  |
| `/camera/detect`  | 객체 탐지     | AI 바운딩 박스            |  ✅  |  Fullscreen   |  ⏳  |
| `/camera/confirm` | 결과 확인     | 탐지 결과 수정            |  ✅  |  Fullscreen   |  ⏳  |
| `/recipe/[id]`    | 레시피 상세   | 모달형 레시피             |  ❌  |     Modal     |  ⏳  |
