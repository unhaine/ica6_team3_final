## 인터랙션

### Bounding Box 드래그

1. 박스 클릭 → 선택 상태 (파란 테두리)
2. 드래그 시작 → 커서 변경 (move)
3. 드래그 중 → 실시간 위치 업데이트
4. 드래그 종료 → 좌표 저장
5. 리사이즈 핸들 → 크기 조절

### 토스트 알림

- 저장 성공: "✅ 식료품 3개가 저장되었습니다"
- 업로드 에러: "❌ 이미지 업로드에 실패했습니다"
- 분석 완료: "🎉 6개의 식료품을 발견했습니다"
