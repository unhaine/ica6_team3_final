# 프로젝트 개요 (1 Page)

## 프로젝트명

**스마트 냉장고 식료품 인식 및 관리 시스템**

---

## 목적 (Why)

스마트폰 카메라로 냉장고 내부를 촬영하면, 사진 속 식료품을 자동으로 인식하여 **현재 냉장고에 어떤 식료품이 있는지 시각적으로 보여주고 저장**하는 것을 목표로 한다.
이를 통해 식재료 관리의 번거로움을 줄이고, 향후 유통기한 관리·레시피 추천 등으로 확장 가능하다.

---

## 핵심 시나리오 (User Flow)

1. 사용자가 스마트폰 또는 웹에서 **사진 업로드**
2. 업로드된 사진을 **Google Vision API**로 전송
3. Vision API가 사진 내 **객체(Object) 탐지 및 분류**
4. 탐지 결과를 기반으로:
   - 원본 사진을 화면에 렌더링
   - YOLO 스타일의 **객체 박스(Bounding Box)** 오버레이 표시
   - 각 박스 상단에 **품목명(Label) + 신뢰도(Confidence)** 표시

5. 사용자는 객체 박스를 **드래그하여 위치 보정** 가능
6. 최종 확정된 식료품 목록을 **저장**

## 주요 기능 (Key Features)

- 이미지 업로드 및 미리보기
- Google Vision API 기반 객체 탐지

- 객체 박스 드래그 및 위치 수정
