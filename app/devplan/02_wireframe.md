┌────────────────────────┐
│ 🥗 냉파고수      [👤]  │ ← 상단 바

│  오늘 뭐 먹을까요?     │
│ 🧊 내 냉장고 (5개)     │ ← shadcn Card

### shadcn 컴포넌트 매핑

| 영역      | 컴포넌트                             |
| --------- | ------------------------------------ |
| 상단 바   | 커스텀 헤더                          |
| CTA 버튼  | `Button` variant="default" size="lg" |
| 카드      | `Card`, `CardHeader`, `CardContent`  |
| 하단 내비 | 커스텀 BottomNav                     |

## 3. AI 분석 결과 (/test/review)

> ⚠️ **중요**: 냉장고 사진과 영수증에 따라 UI가 완전히 다름

---

### 3a. 냉장고 사진 → 바운딩박스 UI (`?type=fridge`)

**핵심 기능**:

- 이미지 위에 드래그 가능한 바운딩 박스 표시
- 박스 라벨 클릭 시 텍스트 인라인 수정
- 확인 버튼 → 레시피 추천으로 이동

```
┌────────────────────────┐
│ ←  분석 결과           │
├────────────────────────┤
│ 🤖 AI가 인식한 식재료   │
│ 박스를 드래그하거나    │
│ 라벨을 클릭해 수정하세요│
├────────────────────────┤
│ ┌────────────────────┐ │
│ │                    │ │
│ │  (냉장고 이미지)   │ │ ← BoundingBoxCanvas
│ │  ┌────────┐        │ │
│ │  │🥛 우유 │  ← 클릭 │ │    라벨 클릭 → 인라인 수정
│ │  │        │  시 수정│ │    박스 드래그 → 위치 이동
│ │  └────────┘        │ │
│ │       ┌────────┐   │ │
│ │       │🥕 당근 │   │ │
│ │       └────────┘   │ │
│ │  ┌────────────┐    │ │
│ │  │🥬 김치     │    │ │
│ │  └────────────┘    │ │
│ │                    │ │
│ └────────────────────┘ │
│                        │
│   [박스를 드래그하여   │
│    위치 조정 가능]     │
├────────────────────────┤
│ ┌──────────┐ ┌──────────┐ │
│ │ ➕ 새 박스 │ │ ✅ 식재료  │ │ ← 좌: 추가 / 우: 완료(확격)
│ │    추가    │ │    완료    │ │
│ └──────────┘ └──────────┘ │
├────────────────────────┤
│ [홈] [업로드] [레시피] │
└────────────────────────┘
```

### 3a-1. 바운딩박스 라벨 클릭 → 인라인 수정

```
┌────────────────────────┐
│  (냉장고 이미지)       │
│  ┌──────────────────┐  │
│  │ 🥛 [우유    ]  ✕ │  │ ← 인라인 Input 활성화
│  │    └ 클릭하여 수정  │  │    ✕ 클릭 시 박스 삭제
│  └──────────────────┘  │
│                        │
└────────────────────────┘
```

**인터랙션**:

| 동작                | 결과                       |
| ------------------- | -------------------------- |
| **박스 드래그**     | 위치 이동 (x, y 좌표 변경) |
| **라벨 클릭**       | 인라인 텍스트 Input 활성화 |
| **Enter 키**        | 수정 완료                  |
| **✕ 버튼**          | 해당 박스 삭제             |
| **➕ 새 박스 추가** | 새 바운딩박스 생성         |

### 3b. 영수증/구매내역 → 리스트 UI (`?type=receipt`)

**핵심 기능**:

- 인식된 식재료 카드 리스트 표시
- 각 항목 클릭 시 인라인 수정 가능
- 확인 버튼 → 레시피 추천으로 이동

```
┌────────────────────────┐
│ ←  분석 결과           │
├────────────────────────┤
│ 🧾 인식된 식재료 (5개)  │
│ 항목을 탭하여 수정하세요│
├────────────────────────┤
│                        │
│ ┌────────────────────┐ │
│ │ 🥩 [삼겹살]        │ │ ← 클릭 시 인풋 활성화
│ │    [300] [g ▼]     │ │ ← 수량 + 단위 선택
│ │               [🗑️] │ │ ← 삭제 버튼
│ └────────────────────┘ │
│                        │
│ ┌────────────────────┐ │
│ │ 🧅 [양파]          │ │
│ │    [3] [개 ▼]      │ │
│ │               [🗑️] │ │
│ └────────────────────┘ │
│                        │
│ ┌────────────────────┐ │
│ │ 🥛 [우유]          │ │
│ │    [1] [L ▼]       │ │
│ │               [🗑️] │ │
│ └────────────────────┘ │
│                        │
│ ─ ─ ← 스와이프하여 삭제 │
│                        │
│ ┌──────────┐ ┌──────────┐ │
│ │ ➕ 항목    │ │ ✅ 식재료  │ │ ← 좌: 추가 / 우: 완료
│ │    추가    │ │    완료    │ │
│ └──────────┘ └──────────┘ │
├────────────────────────┤
│ [홈] [업로드] [레시피] │
└────────────────────────┘
```

### 3b-1. 항목 수정 상태

```
┌────────────────────────┐
│ ┌────────────────────┐ │
│ │ 🥩 ┌──────────────┐│ │
│ │    │ 삼겹살       ││ │ ← 포커스된 Input
│ │    └──────────────┘│ │
│ │    ┌────┐ ┌──────┐ │ │
│ │    │ 300│ │ g  ▼ │ │ │
│ │    └────┘ └──────┘ │ │
│ │         [취소][저장]│ │
│ └────────────────────┘ │
└────────────────────────┘
```

**인터랙션**:

| 동작                   | 결과                     |
| ---------------------- | ------------------------ |
| **항목 탭**            | 인라인 수정 모드 진입    |
| **식재료명 수정**      | 텍스트 변경              |
| **수량/단위 수정**     | 숫자 Input + 단위 Select |
| **🗑️ 버튼 / 스와이프** | 항목 삭제                |
| **➕ 항목 추가**       | 빈 항목 추가             |
| **저장**               | 수정 완료                |

## 🎨 shadcn/ui 컴포넌트 사용 목록

| 컴포넌트      | 용도                     |
| ------------- | ------------------------ |
| `Button`      | CTA, 액션 버튼           |
| `Card`        | 식재료 카드, 레시피 카드 |
| `Input`       | 텍스트 입력              |
| `Select`      | 드롭다운 선택            |
| `Checkbox`    | 식재료 선택              |
| `Progress`    | 매칭률 바, 업로드 진행률 |
| `Skeleton`    | 로딩 상태                |
| `Alert`       | 팁, 안내 메시지          |
| `Badge`       | 태그, 상태 표시          |
| `Sheet`       | 바텀시트 (모달 대체)     |
| `Tabs`        | 타입 선택 토글           |
| `Collapsible` | 접이식 섹션              |
| `Toast`       | 알림 메시지              |
