## 기록 방법

1. 변경사항이 생기면 해당 날짜 파일에 기록
2. 파일명: `YYYY-MM-DD.md` (예: `2026-01-12.md`)
3. 버전 릴리즈 시 별도 파일 생성: `vX.X.X.md`

## 변경 유형 가이드

| 태그 | 설명 | 예시 |
|------|------|------|
| **Added** | 새로운 기능 추가 | 새 페이지, 새 컴포넌트, 새 API |
| **Changed** | 기존 기능 변경 | UI 수정, 로직 변경, 리팩토링 |
