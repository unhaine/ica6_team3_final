# 📖 용어집 (Glossary)

> 바이브코딩에서 사용하는 용어들

---

## 🎯 바이브코딩 관련

| 용어 | 설명 |
|------|------|
| **바이브코딩** | AI 코딩 어시스턴트와 대화하며 개발하는 방식 |
| **세션** | AI와 대화하는 한 번의 작업 시간 (예: 오후 2시~4시) |
| **프롬프트** | AI에게 보내는 요청/명령 (예: "로그인 기능 만들어줘") |
| **맥락(Context)** | AI가 프로젝트를 이해하기 위한 정보 |

---

## 📋 프로젝트 관련

| 용어 | 설명 |
|------|------|
| **MVP** | Minimum Viable Product. 핵심 기능만 있는 최소 버전 |
| **Phase** | 프로젝트 단계 (Phase 1 = 1단계) |
| **마일스톤** | 중요한 중간 목표점 |
| **스프린트** | 짧은 개발 주기 (보통 1~2주) |
| **백로그** | 나중에 할 일 목록 |

---

## 💾 데이터베이스 관련

| 용어 | 설명 |
|------|------|
| **DB** | Database. 데이터를 저장하는 곳 |
| **테이블** | 데이터를 행/열로 정리한 것 (엑셀 시트 비슷) |
| **컬럼** | 테이블의 열 (예: 이름, 이메일) |
| **row/레코드** | 테이블의 행 (실제 데이터 한 줄) |
| **PK** | Primary Key. 고유 식별자 (예: id) |
| **FK** | Foreign Key. 다른 테이블 참조 |
| **ERD** | Entity Relationship Diagram. 테이블 관계도 |
| **스키마** | DB 구조 설계도 |
| **마이그레이션** | DB 구조 변경 작업 |

---

## 🔌 API 관련

| 용어 | 설명 |
|------|------|
| **API** | 서버와 클라이언트가 통신하는 방법 |
| **엔드포인트** | API 주소 (예: `/api/users`) |
| **GET** | 데이터 조회 요청 |
| **POST** | 데이터 생성 요청 |
| **PATCH/PUT** | 데이터 수정 요청 |
| **DELETE** | 데이터 삭제 요청 |
| **CRUD** | Create, Read, Update, Delete (기본 데이터 작업) |
| **Request** | 요청 (클라이언트 → 서버) |
| **Response** | 응답 (서버 → 클라이언트) |
| **JWT** | JSON Web Token. 인증 토큰 |

---

## 🖥️ 프론트엔드 관련

| 용어 | 설명 |
|------|------|
| **컴포넌트** | 재사용 가능한 UI 조각 (버튼, 카드 등) |
| **페이지** | 화면 하나 (예: 로그인 페이지) |
| **레이아웃** | 페이지 전체 구조 (헤더 + 본문 + 푸터) |
| **라우팅** | URL에 따라 페이지 연결 |
| **상태(State)** | 데이터의 현재 값 |
| **Props** | 컴포넌트에 전달하는 데이터 |
| **반응형** | 화면 크기에 따라 레이아웃 변경 |
