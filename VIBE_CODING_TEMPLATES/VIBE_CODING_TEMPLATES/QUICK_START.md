# 🚀 퀵 스타트 (5분 안에 시작하기)

> 바이브코딩 처음이세요? 이것만 따라하세요!

---

## Step 1: 템플릿 복사 (1분)

```bash
# 1. 새 프로젝트 폴더 생성
mkdir my-project

# 2. 템플릿 파일들을 새 폴더로 복사
cp -r VIBE_CODING_TEMPLATES/* my-project/

# 3. 이동
cd my-project
```

> **이미 프로젝트가 있나요?**  
> `cp -r VIBE_CODING_TEMPLATES/* .` 명령어로 덮어쓰기 전에 기존 파일을 백업하세요!
> 또는 필요한 파일(`PROGRESS.md`, `docs/`)만 골라서 복사하세요.

---

## Step 2: AI에게 프로젝트 설명하기 (2분)

AI 코딩 어시스턴트에게 이렇게 말하세요:

```
나는 [프로젝트 설명]을 만들고 싶어.

docs/00_START_HERE.md 파일을 내 프로젝트에 맞게 채워줘.
기술 스택은 [Next.js/React/등]으로 할 거야.
```

**예시:**
```
나는 중고거래 앱을 만들고 싶어.

docs/00_START_HERE.md 파일을 내 프로젝트에 맞게 채워줘.
기술 스택은 Next.js + Supabase로 할 거야.
```

---

## Step 3: 나머지 문서도 채우기 (2분)

AI가 `00_START_HERE.md`를 채워주면, 이어서:

```
이제 docs/01_SERVICE_OVERVIEW.md도 채워줘.
그리고 docs/02_FEATURES.md에 
MVP에 필요한 기능들을 정리해줘.
```

---

## Step 4: 개발 시작!

문서가 어느 정도 채워지면:

```
PROGRESS.md를 오늘 날짜로 업데이트하고,
TODO.md에 오늘 할 일을 정리해줘.
그리고 첫 번째 할 일부터 시작하자.
```

---

## 🔄 매일 하는 루틴

### 세션 시작할 때
```
PROGRESS.md와 SESSION_LOG.md 읽고
현재 상황 파악한 후 TODO.md에서 다음 할 일 진행해줘
```

### 세션 끝날 때
```
오늘 세션 정리해줘:
1. SESSION_LOG.md에 오늘 기록 추가
2. PROGRESS.md 업데이트
3. TODO.md 정리
```

```
막혔어. 지금 상황은 [설명].

```

### 문서 업데이트 요청
```
방금 [기능]을 구현했어.
관련 문서들 업데이트해줘:
- docs/02_FEATURES.md 상태 변경

```
