# 🎸 바이브 코딩 템플릿

> **새 프로젝트를 시작할 때 이 폴더를 복사해서 사용하세요!**

## 사용법

```bash
# 1. 새 프로젝트 폴더 생성
mkdir my-project

# 2. 템플릿 복사
cp -r VIBE_CODING_TEMPLATES/* my-project/

# 또는 특정 파일만 복사
cp VIBE_CODING_TEMPLATES/PROGRESS.md my-project/
cp VIBE_CODING_TEMPLATES/TODO.md my-project/
```

## 포함된 템플릿

```
VIBE_CODING_TEMPLATES/
├── README.md                   # 이 파일
├── QUICK_START.md              # 🚀 5분 안에 시작하기 (먼저 읽기!)
├── VIBE_CODING_RULEBOOK.md     # 📖 바이브 코딩 상세 가이드
├── GLOSSARY.md                 # 📖 용어집
├── UPDATE_GUIDE.md             # 📋 문서 업데이트 가이드
├── PROGRESS.md                 # 📊 프로젝트 진행 상황
├── SESSION_LOG.md              # 📝 세션별 작업 기록  
├── TODO.md                     # ✅ 할 일 목록
│
├── changelog/                  # 🔄 변경 이력 (변경 시마다)
│   ├── README.md
│   ├── 2026-01-12.md           # 날짜별 기록
│   └── v0.1.0.md               # 릴리즈 기록
│
└── docs/                       # 📚 프로젝트 문서
    ├── 00_START_HERE.md        # 시작점
    ├── 01_SERVICE_OVERVIEW.md  # 서비스 개요
    ├── 02_FEATURES.md          # 기능 명세
    ├── 03_DATABASE.md          # DB 구조
    ├── 04_API.md               # API 설계
    ├── 05_UI_STRUCTURE.md      # UI 구조
    └── 99_DECISIONS.md         # 기술 결정
```

## 각 문서의 역할

| 문서 | 역할 | 업데이트 빈도 |
|------|------|:------------:|
| `QUICK_START.md` | **5분 안에 시작하기** (초보자 필독!) | 참고용 |
| `GLOSSARY.md` | 용어 설명 | 참고용 |
| `UPDATE_GUIDE.md` | 문서 업데이트 방법 안내 | 참고용 |
| `PROGRESS.md` | 현재 진행 상황, 타임라인 | **매일** |
| `SESSION_LOG.md` | 세션별 상세 기록 (삽질, 배운 것) | 매 세션 |
| `TODO.md` | 할 일 목록 관리 | 수시 |
| `changelog/` | 변경 이력 (변경 시마다 기록) | 변경 시 |
| `VIBE_CODING_RULEBOOK.md` | 상세 가이드 (필요할 때 참고) | 참고용 |
| `docs/00_START_HERE.md` | 프로젝트 입구 | 초기 |
| `docs/01_SERVICE_OVERVIEW.md` | 서비스 설명 | 초기 |
| `docs/02_FEATURES.md` | 기능 목록 & 상태 | 기능 변경시 |
| `docs/03_DATABASE.md` | DB 스키마 | DB 변경시 |
| `docs/04_API.md` | API 엔드포인트 | API 변경시 |
| `docs/05_UI_STRUCTURE.md` | 페이지 & 컴포넌트 | UI 변경시 |
| `docs/99_DECISIONS.md` | 기술 결정 기록 | 결정시 |
